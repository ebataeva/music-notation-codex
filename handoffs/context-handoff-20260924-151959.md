### Две ловушки, найденные фактически

1. **Имя npm-пакета OpenSpec.** `npm install -g openspec` ставит **мёртвый плейсхолдер версии `0.0.0` от 2019 года** (publisher `akerust`, репозиторий `openspecio/openspec`). Настоящий пакет — **`@fission-ai/openspec`**, версия 1.13.1, bin `openspec`. Ни `openspec`, ни `specify` в PATH сейчас нет.
2. **Spec Kit ставится через `uv`**, который на машине есть: `uvx --from git+https://github.com/github/spec-kit.git specify init .`. Доступны также `node`, `npx`, `codex`, `claude`.
